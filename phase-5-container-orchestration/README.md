# Phase 5 — Container Orchestration

> Long-running containers, described as code.

Moves the service onto **ECS Fargate**, with the whole stack defined in **Terraform** — the project's shift to Infrastructure as Code. Trades Lambda's cold-start and timeout constraints for a right-sized, always-warm container platform, and trades click-ops for a reproducible, version-controlled deployment.

**Stack:** AWS ECS Fargate · Terraform · Docker · ECR
